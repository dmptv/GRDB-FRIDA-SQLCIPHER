## Git commits

Never include any mention of Claude, Anthropic, or any AI vendor/tool name in
commit messages — no `Co-Authored-By: Claude ...` trailer, no other reference.
Commits must read as if written entirely by the human author.

Workflow: commit to `dev`, push, then fast-forward merge `dev` into `main` and
push `main`.
